## 2. What changed

### 2.1 Welcome — rebuilt as a bounded institutional hero (CSS-only)

`PhoenixWelcomeExperience.tsx` is **byte-for-byte unchanged** (confirmed by
the new contract test) — every skip/timing/completion handler is identical.
Only `src/shared/lib/phase-a-visual-convergence.css`'s `.nexus-welcome*`
rules changed, replacing the full-viewport dark cinematic backdrop with:

- a light institutional canvas (`--bg`/`--surface`/`--text` — the same
  tokens every other daylight surface uses, so Welcome now follows the
  light/dark toggle instead of forcing one fixed dark identity);
- a **bounded** hero panel (rounded, shadowed, `clamp(180–320px)` tall)
  holding the same approved Phoenix artwork, instead of a full-bleed
  background;
- the title below the hero (gold kicker, plain ink text, no text-shadow —
  no longer needs one, since it no longer overlays the photo);
- a clearly bordered, opaque credits card (no glass/blur) for the exact
  approved issuance/supervision text;
- the 18 drifting ember particles hidden (`display:none`) — a calmer
  institutional surface, no new motion;
- a calm gold progress bar, same position, same `phase-a-welcome-progress`
  keyframe/timing (6s) already defined by A2 — only its colour/height changed.

No WebGL, no canvas, no new animation. Reduced-motion, RTL/LTR, and the
existing dual-theme handling all inherited unchanged from the shared
convergence layer's global rules (untouched).
