# Pharma Molecular — مرشح واجهات البرنامج الفعلية

التاريخ: 2026-10-30 بتوقيت بغداد.
الأساس الحالي: master `73928eb36fa4116ffe1ee48e7435d0d85dc15252`، شجرة `2c8acd486cbd3cc11712114cb518a2a1825393be`. فُصل هذا المرشح عن أساس PR #256 القديم، الذي لا يدخل النطاق. أرقام الفحوص التاريخية أدناه تخص المرشح السابق حتى يصدر تقرير هذه النسخة المستقلة.

## تفويض المالك

«اذا ابدء لجميع واجهات البرنامج والصور تكون معيارا للحركات والالوان والعمق ونوع الخط والاشكال والنمط وليس html دون كسر للبرنامج».

هذا تنفيذ تقديمي داخل مكونات React الحالية، وليس تطبيق HTML بديلًا ولا واجهة فوق بيانات وهمية في الإنتاج. معرض المراجعة وحده يستخدم بيانات مصطنعة معلنة؛ المكونات والخدمات الإنتاجية تحتفظ بعقودها. لا يشمل التفويض الحالي نشرًا أو commit أو push أو دمجًا أو SQL أو Production أو تغيير الصلاحيات أو Flags.

## مرجع التصميم المعتمد

ثلاث صور المالك: Molecular Desk للحاسوب، Dose Pocket للهاتف، Compound Canvas للتابلت. استُخدم منها الصنوبر والعاجي والمريمي والنحاس الهادئ، الحافة المنحوتة والظل الناعم والكبسولة والجزيئات. لا يُدّعى التعرف على ملف الخط الأصلي داخل الصورة أو التطابق البكسلي مع صورة مولدة. الخط العملي IBM Plex Sans Arabic المستضاف محليًا، مع خطوط النظام/Inter الموجودة؛ لا تنزيل خطوط أو حزم جديدة. شعار Phoenix الصيدلاني الذي اعتمده المالك محفوظ بايتيًا.

الكبسولة SVG زخرفية مع تدرج ولمعان ومعرّفات gradients فريدة لكل نسخة؛ ليست صورة المادة، وليست تمثيلًا للجرعة أو صلاحية المادة أو مرحلة اعتماد. عنوان الصفحة والنصوص والبيانات عناصر React حية وليست نصوصًا مخبوزة داخل الصور.

## حدود التطبيق

- 25 ملف شاشة فعليًا، بما فيه الشاشات القديمة المخفية أو المحالة: الحصر لا يعيد إتاحتها في التنقل.
- 35 مكوّن UI مشتركًا في الحصر، و14 مكوّن Dialog/Modal مسمّى في شجرة المصدر. هذا عدد المصدر، وليس ادعاء أن كل فرع شرطي في كل نافذة قد اختُبر.
- الهيكل العام، التنقل، الرؤوس، البطاقات، الأزرار، الحقول، التبويبات، الجداول، حالات الفراغ والخطأ والتحميل والنوافذ ترث الهوية الجديدة.
- مساحة الإدخال اليدوي حصلت على تنسيق لحقولها الأصلية وسجلها، وغلاف تمرير أفقي مُسمّى للجدول مع إمكان وصول بلوحة المفاتيح. ترتيب أعمدة الجدول وبياناته وأزراره محفوظ.
- تسجيل الدخول والترحيب يحافظان على تدفق الدخول، كلمة المرور، توقيت الترحيب والتخطي والنصوص المعتمدة.

## الأجهزة

| الجهاز | التكوين الفعلي |

| الهاتف حتى 767px | رأس صنوبرى وغطاء عمل عاجي مستدير؛ قائمة جانبية من زر القائمة دون شريط سفلي؛ الحقول رأسية؛ النافذة المشتركة sheet من الأسفل؛ الجداول تبقى جداول مع تمرير محلي |

اللغتان AR/EN والوضعان light/dark عبر مالكيهما الحاليين؛ لا تفضيلات تخزين جديدة. يحترم التصميم RTL/LTR والحواف الآمنة. القيم الآتية من الخادم ليست مصدرًا لاختيار اللون الزخرفي، ولا يحوّل التصميم المسودة إلى معتمدة.

## الحركة

240ms لمعظم استجابات السطح، و480ms للاستجابة الزخرفية في الكبسولة عند المؤشر. لا حركة متكررة دائمة للزخرفة، ولا صفوف بيانات تطفو أو تتغير أثناء القراءة. احترام `prefers-reduced-motion` يلغي الحركة والانتقالات؛ النوافذ تحتفظ بالفوكس وEscape وإعادته، والتحميل يحتفظ بنص حالته. قواعد forced-colors والطباعة مستقلة. هذا ليس قياس FPS أو بطارية ولا شهادة WCAG.

## ضمانات عدم تغيير الأعمال

لم تُعدّل `AppContext` أو مصادر الصلاحيات أو إسقاط التنقل أو الموجّه أو RLS أو RPC أو SQL أو الخدمات أو الاستيراد أو حساب الكميات أو FEFO أو الوحدات أو الفصل/السياسة بين الأشخاص أو الرمز الوطني/الباركود أو الـlockfile والحزم أو workflows.

فحص AST الأولي سبق قرار تقاعد الدليل والتنقل السفلي؛ كان يقارن المعالجات والاستدعاءات وشروط التفرع مع الأساس. بعد قرار المالك، إزالة استدعاءات مضيف الدليل وتركيب الشريط متعمدة، وتثبتها اختبارات الغياب والتنقل الجديدة. مصادر الصلاحيات والخدمات لم تتغير؛ لا يحل فحص البنية محل اختبارات الأعمال أو الخادم.

## معرض المراجعة

`design/pharma-review/` أدوات تطوير فقط خارج الرسم البياني للإنتاج، تعرض مكونات الشاشات الفعلية ضمن QaAppProvider وناقل fixtures الموجودين. كل كتابة خارج fixtures المصرح بها أصلًا تُرفض؛ سيناريو الإدخال اليدوي هنا يرفض الكتابات جميعها. لا جلسات حقيقية أو كلمات مرور أو توكنات أو اتصال Production. ملف HTML هناك محمّل React فقط، وليس نموذج التصميم المبسط السابق.

لتشغيل المراجعة محليًا يُستخدم Vite الحالي مع `VITE_ENABLE_VISUAL_QA=true`، ثم `/design/pharma-review/index.html?surface=manual&lang=ar&theme=light&persona=super_admin`. لا تُنشأ أو تُعدّل قيمة هذا المتغير على Vercel. فحص الحزمة الإنتاجية، حتى مع علم QA المحلي، يجب أن يثبت غياب المعرض والبيانات المصطنعة منها.

## بوابات القبول

الهدف مرشح تقديمي قابل للمراجعة على جميع الشاشات الموجودة، لا ادعاء إغلاق كل رحلة أعمال. يلزم قبل أي إصدار فحص CI على المرشح الملتزم، مراجعة بصريّة للواجهات ذات البيانات الواقعية المصرّح بها، وقبول المالك. لا يُغلق R1 بهذا التغيير؛ تبقى فجوة المصنف المعلّق والتعديل اليدوي في PR #256 على HOLD، ولا تُسوّى بواسطة التصميم.

حُفظت نتائج التنفيذ الأولي وحالات فشله ومصفوفة المتصفح في الحزمة التاريخية دون تعديل. مواءمة الاختبارات التالية مبنية على قرار المالك الصريح بإزالة ميزتين، لا لتجاوز عيب عرض أو صلاحيات.

## تعديل اعتماد المالك — 2026-10-30

اعتمد المالك التصميم وطلب إزالة التنقل السفلي للهاتف ودليل المساعدة من جميع الواجهات. أُزيل تركيب الشريط السفلي، ومشغّل الدليل وأزراره في الرأس والقائمة الجانبية، مع إبقاء سياق وصف الشاشات خاملًا للتوافق. لم تُحذف الصفحات أو تُغيّر إسقاطات الصلاحيات. أزيل الفراغ المحجوز للشريط مع حفظ الحافة الآمنة. اختبارات جولات الدليل القديمة التي تتوقع وجوده تمثل عقدًا متقاعدًا بهذا القرار، وليست دليل قبول للتصميم الجديد. لا يشمل الاعتماد دمجًا أو نشرًا على التطبيق الأصلي أو تعديل بيانات.

تحقق هذه الجولة: typecheck وlint والبناء الإنتاجي ناجحة على Node 22.23.3، واختبارات إسقاط التنقل وتكافؤه وحفظ الصلاحيات ناجحة (88 حالة؛ صفر فشل). فُحصت المعاينة الفعلية في متصفح CUA للهاتف/التابلت/الحاسوب؛ زر القائمة يعمل وانتقل إلى حسابي، والدليل والشريط غائبان. هذه كانت نتيجة الجولة السابقة قبل مواءمة اختبارات الإزالة؛ يُرجع إلى ملحق الاستكمال التالي لحالتها الحالية.

## استكمال تفويض المالك — مواءمة القبول

استُبدلت اختبارات تركيب دليل المساعدة وجولاته في ملفات Chromium الثلاثة باختبارات غيابه في الهيكل الحقيقي، مع التحقق من القائمة الجانبية وEscape والفوكس واللغة والمظهر والحواف الآمنة والتكافؤ بين التنقل على الهاتف والحاسوب. احتُفظ باختبارات صلاحيات المخزون المقيدة وتغيير المخزن ورفض المنفذ غير المخول. لم تُضف skip أو تسمح بنتيجة مرفوضة.

اختبار `guide-ig3-panels.runtime` أصبح اختبارًا معلنًا لمحرك الدليل المتبقي فقط: يركّب مضيفًا وزرًا داخل الاختبار لا داخل الهيكل الإنتاجي. حافظ على دورته الفعلية وقيود القراءة وعدم الكتابة مع مكونات المخزون الحقيقية؛ ليس دليلًا على وجود الميزة في المنتج. بقيت اختبارات المحرك الأخرى دون تغيير. أزيلت معاملات `onOpenGuide` التي تقاعدت من واجهات مكونات الرأس والقائمة.

مواءمة توقعات الفراغ السفلي والشريط اقتصرت على اختبارات الهيكل المعنية. حراس stash الستة بقيت كما هي، ولم تُنشأ stash اصطناعية. لا نشر GitHub ولا SQL ولا CI بعيد ولا تغيير Production في هذا الاستكمال. نتائج المحاولات الأولى محفوظة في أدلة الاستكمال؛ لا يُعتبر فحصنا الذاتي مراجعة مستقلة أو إغلاقًا لـR1.
